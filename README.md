# homebrew-tap

Official Homebrew tap for [degunk](https://github.com/AbdullahHassan192/degunk).

## Installation

```bash
brew install abdullahhassan192/tap/degunk
```

Or add the tap first:

```bash
brew tap abdullahhassan192/tap
brew install degunk
```

## Updating

```bash
brew update
brew upgrade degunk
```
